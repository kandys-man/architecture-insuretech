# Список проблем и рисков, связаных с планируемым ростом нагрузки

1. Сервисы `core-app`, `ins-comp-settlement` и `ins-product-aggregator` обмениваются запросами синхронно, что:
   - увеличивает связность компонентов
   - увеличивает время на обработку запросов
   - снижает надёжность системы

2.  Нарушен паттерн `source of truth` для сервисов `core-app` и `ins-comp-settlement`, что может привести с рассинхронизации по времени.
